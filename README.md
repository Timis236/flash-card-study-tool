# Overview
A little tool I made to help study for my MA323 exam at WLU.

This is a flashcard-type studying tool, using Python tkinter to display a GUI showing a term on one "side" and its definition on the other, with a button to flip between the two. You can choose either the random mode, where terms appear at random, or the test mode, where all terms appear exactly once before restarting. Currently it is hard-coded to my list of definitions that I used in MA323, but I may return to this at some point to make it more general use...
