binary (algebraic) structure&a set S with a given binary operation (denoted by (S, ∗))
closed under ∗ (for a binary structure)&a ∗ b ∈ H for all a, b ∈ H
homomorphism&a map φ : S → S’ of 2 algebraic structures (S, ∗), (S’, ∗’) such that φ(x ∗ y) = φ(x) ∗’ φ(y) for all x, y ∈ S
isomorphism&a homomorphism that is 1-1 and onto (denoted by S ≅ S’ or (S, ∗) ≅ (S’, ∗’))
group&binary structure (G, ∗) such that the following axioms hold: (a ∗ b) ∗ c = a ∗ (b ∗ c) for all a, b, c ∈ G, there exists an identity e such that e ∗ a = a ∗ e = a for all a ∈ G, and for all a ∈ G, there exists an inverse a’ ∈ G such that a ∗ a’ = a’ ∗ a = e (a-1 := a)
abelian group&any group with a commutative binary operation
finitely generated group&a group such that there exists finitely many elements x1, ..., xs in G such that every element in G can be written as a linear combination of those elements
order of a group&cardinality (or number of elements in its set) of the group, denoted by |G|
homomorphic groups&groups such that a map Φ : G → G’ can be defined which is a homomorphism of the binary structures (Φ(ab) = Φ(a)Φ(b) for all a, b ∈ G)
isomorphic groups&two groups (G, ·G) and (H, ·H) which are isomorphic as binary structures (denoted as G ≅ H)
subgroup&a subset H ⊆ G which is a group with the same operation as G (denoted by H ≤ G)
cyclic subgroup of G (generated by a)&〈a〉 = {a^n | n ∈ ℤ}
center (of a group G)&Z(G) = {a ∈ G | ag = ga for all g ∈ G} ≤ G
centralizer (of a in G)&ZG(a) = {x ∈ G | ax = xa} ≤ G
coprime / relatively prime integers&integers k1, …, kr such that gcd(k1, …, kr) = 1
Euler's φ-function&numbers of integers between 1 and n which are relatively prime to n (φ(n) = n(1 - 1/p1)(1 - 1/p2)...(1 - 1/ps))
exponent (of a group G)&smallest integer n such that a^n = e for all a ∈ G
subgroup generated by S&smallest subgroup of G containing S ⊆ G (denoted 〈S〉)
permutation (on a nonempty set A)&any bijective map φ : A → A
symmetric group (on n “letters”)(Sn)&the group (SA, ୦), where SA or Sym(A) is the set of all permutations of A
orbit (of a under σ)&the equivalence class [a] = Oσ(a) = {σ^n(a) | n ∈ ℤ} ⊆ A
cycle&a permutation which has at most 1 orbit containing more than 1 element
length (of a cycle)&number of elements in the largest orbit (equal to / denoted by |σ|)
disjoint cycles (σ1, …, σk)&each m ∈ {1, 2, …, n} is moved by at most one σj, (σj(m) = m for all j but at most one)
transposition&a cycle of length 2 in a symmetric group
cycle type (of a permutation σ)&increasing list of cycle lengths in a bracket when σ is written in a product of disjoint cycles (unique)
even/odd permutation&defining sgn(σ) = (-1)^l, for a product of transpositions σ = τ1…τl, if sgn(σ) = 1, σ is even, and if sgn(σ) = -1, σ is odd
alternating group&An = {σ ∈ Sn | σ is even}
left/right cosets (of H, containing G)&all elements of H operated on by a representative element g ∈ G (gH = {g}H = {gh : h ∈ H} is left and Hg = H{g} = {hg : h ∈ H} is right)
G / H&{all left cosets of H} = {giH | i ∈ I}
index (of H in G)&the number of possible left cosets of H, |I| = |G / H| (denoted as (G : H))
direct product (on G = G1 x G2 x … x Gn)&operation defined as (a1, a2, …, an) · (a1, a2, …, an) = (a1b1, a2b2, …, anbn), where ai, bi ∈ Gi
Betti number&name of the parameter n in the group of direct product of nontrivial cyclic groups ℤm1 x ℤm2 x … x ℤmr x ℤ^n that every nontrivial finitely generated abelian group is isomorphic to
epimorphism&a homomorphism that is onto
monomorphism&a homomorphism that is 1-1
kernel (of ɸ : G → G')&defined to be equal to ɸ^-1(e’) (or equivalently, {x ∈ G : ɸ(x) = e’}) (denoted ker(ɸ))
normal (subgroup)&a subgroup H ≤ G such that gH = Hg for all g ∈ G (left and right cosets coincide) (denoted by H ⊴ G)
factor/quotient group (of G by H)&the group G / H where H ⊴ G
commutator/derived subgroup&subgroup H defined by H = 〈aba^-1b^-1〉 for all a, b ∈ G (cyclic subgroup generated by aba^-1b^-1) (denoted by [G, G])
automorphism (of G)&an isomorphism from G to G
automorphism group (of G)&the set of all automorphisms of G (denoted Aut(G))
inner automorphism group (of G)&the group defined by {ig : g ∈ G) (denoted Inn(G)), where ig : G → G, ig(x) ↦ gxg^-1 for all x ∈ G
simple group&a group G which only has the trivial subgroups G and {e} as its normal subgroups
maximal normal subgroup (of G)&a normal subgroup M ≠ G such that there does not exist a proper normal subgroup N properly containing M
ring&nonempty set R with two operations + and · such that: (R, +, 0) is an abelian group (0 is the identity), multiplication (·) is associative, and the distributive property is true ((a + b)c = ac + bc and a(b + c) = ab + ac for all a, b, c in R)
ring homomorphism&a map φ : R -> R’ such that φ satisfies the homomorphism properties φ(x + y) = φ(x) + φ(y) and φ(xy) = φ(x)φ(y) for all x, y in R
unity&multiplicative identity of a ring, denoted by 1 (if it exists)
commutative ring&the multiplication of the ring is commutative
unital ring&a ring with unity 1 such that 1 ≠ 0
invertible (element in a unital ring)&an x in R such that there exists a y in R such that xy = yx = 1
inverse&the unique element y = x^-1 that satisfies xy = yx = 1 (the element which makes x invertible)
unit&any element x in R such that x is invertible
unit group&set of all elements x that have an inverse x^-1 (denoted U(R))
irreducible (element)&an element a in R such that a = bc (for b, c in R) implies that either b or c is a unit
division ring / skew field&a unital ring R such that U(R) = R \ {0} (all elements other than 0 are invertible)
field&commutative division ring
subring (of a ring R)&a subset S of R such that (S, +) ≤ (R, +) is a subgroup and (S, ·) ≤ (R, ·) is a substructure (denoted (S, +, ·) ≤ (R, +, ·) or S ≤ R)
idempotent (element)&an element a in R such that a^2 = a
left/right 0-divisor&nonzero elements in a ring which satisfy xy = 0
integral domain (ID)&commutative ring without 0-divisors
characteristic (of a ring R)&a positive integer n such that na = 0 for all a ∈ R (denoted by ch(R) = n)
endomorphism&any morphism from a mathematical object to itself
endomorphism ring&the ring (End(A), +, ·), where (A, +, 0) and End(A) denotes the set of all endomorphisms of A
group ring (RG)&the set defined by Σi∈I aigi where ai ∈ R (gi is fixed) with only finitely many ai ≠ 0
Laurent polynomial (over R)&an element Σi∈ℤ aix^i of the group ring RG, where G = 〈x〉 is an infinite cyclic group and R is a ring
polynomial (over R)&an element Σi∈ℤ aix^i of the group ring RG such that ai = 0 for all i < 0, where G = 〈x〉 is an infinite cyclic group and R is a ring
polynomial ring (over R)&the set of all polynomials over R (denoted by R[x])
degree (of a nonzero polynomial f = Σi∈ℤaix^i)&defined by max{i : ai ≠ 0} (denoted by deg f)
evaluation (at t)&the mapping Φt : Σaix^i ↦ Σait^i from R[x], the set of all polynomials over R, to S
polynomial function&the function R[x] (evaluated at elements of R) from R to R, if R is commutative
ring of polynomials (in n indeterminates with coefficients in R)&inductively defined as R[x1, x2, …, xn] = (R[x1, x2, …, xn])[xn] (set of expressions in the form p = p0 + p1X + p2X^2 + ... + pnX^n)
Weyl algebra (of rank n, over F[x1, x2, …, xn])&the general form of the Weyl algebra, F[X1, …, Xn, ∂/∂X1, …, ∂/∂Xn] = spanF{X1^iX2^i...Xn^i∂1^i∂2^i...∂n^i : i, j ∈ ℤ+}, the set of all linear combinations of X1, ..., Xn and ∂X1, ..., ∂Xn
set of quaternion numbers&the set defined by ℍ = {a1 + bi + cj + dk : a, b, c, d ∈ ℝ}
norm / absolute value (of z ∈ ℍ)&defined as |z| = √(zz̅) = |z̅|
similar (quaternions)&two quaternions g1, g2 ∈ ℍ such that there exists an h ∈ ℍ such that g2 = hg1h^-1 (denoted by g1 ~ g2)
ideal (of a ring R)&an additive subgroup N of R such that aN, Na ⊆ N, for all a ∈ R (denoted by N ⊴ R)
quotient ring (of R by N)&the ring defined as (R/N, +, ·), where R/N = {a + N : a ∈ R}
proper ideal (I, of a ring R)&an ideal I ⊴ R such that I ≠ R (denoted I ⋬ R (the line should only go through the bottom line))
maximal ideal (of a ring R)&a proper ideal M of R such that M ⊆ N ⊴ R implies N = M or N = R (there is no proper ideal of R properly containing M)
prime ideal (N, of a commutative ring R)&a proper ideal N such that ab ∈ N implies a ∈ N or b ∈ N, for all a, b ∈ R
spectrum (of R)&the set of all prime ideals of R
ideal generated (by S)&the smallest ideal of R containing S, where R is a ring and S ⊆ R (denoted by 〈S〉)
principal ideal (of R)&an ideal of R generated by a single element a ∈ R
principal ideal domain (PID) (of R)&an integral domain such that all of its ideals are principal
